# Mission: Jev를 고객사 의사결정자에게 설득하기

## Why
고객사 CTO·PM 같은 의사결정자에게 Jev(TypeSafe AI의 System One Model)가 무엇이고 왜 지금 필요한지 설명하고, 그들의 업무 중 Jev가 맞는 자리와 맞지 않는 자리를 즉석에서 골라내 도입을 제안할 수 있어야 한다. 기술 세부가 아니라 "이 고객의 어떤 문제를 얼마에 얼마나 빨리 푸는가"로 말할 수 있는 상태가 목표다.

## Success looks like
- 비기술 의사결정자에게 5분 안에 Jev를 설명하는 피치를 할 수 있다 (무엇/왜 지금/LLM과 어떻게 다른가/무엇은 못 하는가).
- 고객의 업무 설명을 듣고 Jev 유즈케이스 맵(라우팅·가드레일·모더레이션·리랭킹·스코어링·실시간 루프)에 매핑해 "맞는 자리 3개, 맞지 않는 자리 2개"를 즉석에서 말할 수 있다.
- "그냥 분류기 아니냐", "벤치마크 과장 아니냐", "근거를 안 주는데 감사는 어떻게 하나" 같은 반론에 출처 있는 숫자로 답할 수 있다.
- 벤더 주장(193.6x/444.6x)과 독립 검증 수치(2~3.6x)를 구분해서 말하며 신뢰를 잃지 않는다.

## Constraints
- 주 5시간 이상 투입, 레슨당 30분 안팎, 매일 1개 레슨 가능.
- 학습 언어는 한국어. 피치 자체는 한국어 기준으로 연습한다.
- 코드는 다루지 않는다. API 호출 형태 정도만 그림으로 이해한다.
- 자료 접근 제약: TypeSafe 공식 사이트 원문은 이 환경에서 직접 열 수 없어 GitHub 미러·검색 요약에 의존한다. 확인 못한 수치는 반드시 표기한다.

## Out of scope
- TypeSafe와의 가격 협상·계약 조건·라이선스.
- Noul/Choice/Score 질문 설계나 임계값 튜닝 같은 구현 수준 세부 (→ `learn/jev-tech/` 워크스페이스).
- open-jev 등 오픈 재현 실습.
