## 사용자 선호
- 답변은 항상 3문장 이내로 간결하게. 궁금하면 사용자가 더 깊게 묻는다.
- 학습·레슨 언어: 한국어.
- 코드 없음. 개념·그림·숫자 중심.
- 주 5시간 이상, 레슨당 약 30분, 매일 1개 가능.

## 작업 메모
- 워크스페이스 생성일: 2026-09-22. 미션은 사용자 답변(AskUserQuestion 2회)으로 확정.
- 자매 워크스페이스: `../jev-tech/` (질문 설계·임계값·아키텍처·원리). 겹치는 주제는 tech에 두고 sales는 링크만.
