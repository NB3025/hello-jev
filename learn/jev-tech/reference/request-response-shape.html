한 장에 인쇄해 두고 설계할 때 옆에 두는 용도. 출처: 공식 Quick start, System One, Primitives, Confidence.

계약 한 줄

state(텍스트·JSON·텍스트 배열) + 타입 질문들 → 타입 답 + 확률 (+ confidence). 텍스트 생성 없음. 답 공간은 내가 정의. 모든 질문은 병렬·독립. 엔드포인트 POST /v1/systemone, 모델 jev-latest.

요청

{
  "state": "…" | { … } | [ … ],
  "model": "jev-latest",
  "questions": {
    "<id>": {                  ← 모델은 id를 못 본다
      "type": "choice",
      "instructions": "완전한 질문",
      "criteria": { "opt": "설명", … }   ← ≤255 옵션
    },
    "<id>": {
      "type": "score",
      "instructions": "완전한 질문",
      "criteria": [ "낮음", …, "높음" ]   ← 2~10 레벨
    },
    "<id>": {
      "type": "noul",
      "instructions": "참/거짓 명제",
      "criteria": { "true": "…", "false": "…" }  ← 선택
    }
  }
}

응답

{
  "model": "jev-latest",
  "answers": {
    "<id>": {
      "type": "choice",
      "choice": "opt",
      "probabilities": { "opt": p, … },  ← 합 1
      "confidence": 0~1
    },
    "<id>": {
      "type": "score",
      "score": 1.035,                ← 레벨 사이 값
      "legend": { "0": "…", "1": "…" },
      "probabilities": { … },
      "confidence": 0~1
    },
    "<id>": {
      "type": "noul",
      "noul": 0~1                    ← confidence 없음
    }
  },
  "usage": { "input_tokens": n, "output_tokens": n }
}

프리미티브 선택표

타입언제답 공간돌아오는 것주의
Choice순서 없는 유한 집합에서 하나옵션 이름→설명 맵, 최대 255choice · probabilities · confidence목록이 불완전할 수 있으면 other/none 옵션 추가
Score순서 있는 스펙트럼 위 위치낮음→높음 배열, 2~10 레벨score · legend · probabilities · confidence레벨은 "정도"가 아니라 "상황"을 묘사. 숫자만 쓴 레벨은 동작 안 함
Noul명제의 참일 확률 자체가 신호참/거짓noul (0~1)confidence 없음. 0.5는 "중간"이 아니라 "불확실"

외워야 할 사실 열 가지

  1. Jev는 답장·코드·근거 설명을 만들지 않는다. 답 공간은 내가 criteria로 정의한다.
  2. 질문 ID는 모델에 전달되지 않는다. instructions에 완전한 질문을 쓴다.
  3. 모든 질문은 같은 state에 대해 병렬·독립. 질문을 더해도 지연은 거의 안 늘고, 한 답이 다른 질문의 문맥이 되지 않는다.
  4. confidence는 확률 분포의 형태 통계다. "맞을 확률"이 아니다.
  5. Noul에는 confidence가 없다. noul 값 자체가 신호다.
  6. 캘리브레이션은 집합의 성질. 0.8을 받은 사건 집합이 약 80% 일어난다. 개별 답의 정확성 보장은 아니다.
  7. "환각 0"의 정확한 뜻: 스키마 밖 값은 나오지 않는다. 스키마 안에서 틀린 옵션은 고를 수 있다.
  8. 입력은 텍스트만(문자열·JSON·텍스트 배열). 이미지·오디오·비디오 불가.
  9. 토큰 예산은 state와 질문이 공유, 약 32K 토큰(공식 Primitives 페이지 기준. 다른 페이지는 64K 언급. 확인 중).
  10. 확장 추론이 필요한 질문은 Jev 것이 아니다. 요인별로 쪼개서 묻고 코드에서 합친다.
